# Использование AI-агентов при выполнении задания

Задание выполнялось с помощью Claude Code

1. Агент разобрал код демо-сервиса.
2. Агент перенс код обучения из ноутбука в файл `training/train.py` и общий модуль препроцессинга. Модель обучалась локально на CPU. Первая версия весила 219 МБ (не проходит лимит GitHub), поэтому модель переобучили с `max_ctr_complexity=1`: итоговый размер 1.8 МБ, ROC-AUC 0.997, PR-AUC 0.891.
3. Агент помогал исправлять ошибки в реализации сервисов
4. Проводилась end-to-end проверка с помощью агента.
5. Агент написал README с инструкцией по запуску и проверке и сделал коммит.
